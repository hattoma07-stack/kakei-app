# ふたりの家計簿 👛

夫婦2人で使う家計管理アプリ。あなたの「支出管理＋ライフプランシート」の考え方（敵1〜4の分類・手取り8割ルール・貯蓄率）をそのままアプリにしたものです。

## 使い方（開発サーバー）

```bash
npm install   # 初回のみ
npm run dev   # http://localhost:5173 で起動
```

## いまできること（第1版・ブラウザ内保存）

- **入力**: 夫/妻を選び、費目をタップ → テンキーで金額 → 記録（スマホ最適化）
- **ダッシュボード**: 手取り8割ルール判定、支出率、貯蓄率、敵1〜4の内訳（円グラフ）、年間推移（棒グラフ）
- **履歴**: 月ごとの記録一覧・削除
- **設定**: 費目の追加・削除（分類=敵1〜4等を選択）

※データは現在この端末のブラウザ内（localStorage）に保存されています。

## 設計の考え方

| 用語 | 意味 |
|---|---|
| 手取り(income_in) | 予算内収入（給料・副業など）。8割ルールの分母 |
| 予算外(income_out) | 残業・賞与・売電。8割ルールの分母から除外 |
| 敵1 | 毎月・固定費（住宅・光熱・通信・サブスク・保険） |
| 敵2 | 毎月・変動費（食費・日用品・美容・医療・ガソリン） |
| 敵3 | 不定期・固定費（税・車検・ふるさと納税など） |
| 敵4 | 不定期・変動費（趣味・家電・外食・旅行など） |

会計年度は **2025年9月開始の12ヶ月**（`src/data/seed.ts` の `START_YM`）。
